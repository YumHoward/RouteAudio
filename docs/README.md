## 唯一必须记住的三件事

1. **P1 / P2 是死门槛**：策略 API 可用性、静音与进程回环的关系，必须在写业务代码前有结论（见 04）。
2. **产品价值在「自动化与可解释」**，不在「又一个音量混合器」；因此规则引擎、配置档、原因码、对账自愈都是 P0，不是彩蛋。
3. **宁可「不生效 + 提示」，也不要「没声音 + 崩溃」**：任何后端失败都必须降级并给出原因码。
